## Connection to the Ecosystem

Hub is the WORKSHOP. It doesn't hold identity (that's `~/deji/`), philosophy (that's `~/chimera/`), or the public face (that's `~/reemy/`). It BUILDS.

The holographic-agent is the master orchestrator — most projects live as subdirectories inside it. This is both powerful (everything in one git history) and heavy (25GB repo). Projects that grew large enough got their own top-level directory (neural-arena, assetforge, QuantumLeap-AI, voxel-nexus-core, nano-bot).

See `~/deji/projects/INDEX.md` for the complete map across ALL repos (GitHub + local).
