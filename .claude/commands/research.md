## Research Depth Detection

Parse the topic:
- `quick: <topic>` → Quick lookup (1-2 sources)
- `deep: <topic>` → Deep dive (5+ sources, extended thinking)
- `<topic>` → Standard research (3-5 sources)

---

## Research Protocol

### Step 1: Define Scope

**Primary Question:** What exactly needs to be understood?
**Sub-Questions:**
1. ?
2. ?
3. ?

**Scope Boundaries:** What's in/out of scope?

---

### Step 2: Multi-Source Investigation

#### Official Sources
- Official documentation
- API references
- Release notes/changelogs

#### Community Sources
- GitHub repositories
- Stack Overflow
- Blog posts from practitioners

#### Expert Sources
- Conference talks
- Technical deep-dives
- Academic papers (if applicable)

---

### Step 3: Extended Thinking Analysis

**For deep research, use these trigger phrases:**
- "think" - Standard analysis
- "think hard" - Deeper analysis
- "think harder" - Extensive reasoning
- "ultrathink" - Maximum depth

Apply to:
- Synthesizing conflicting information
- Evaluating trade-offs
- Formulating recommendations

---

### Step 4: Structure Findings

```markdown
# Research: $ARGUMENTS

## Executive Summary
<2-3 sentences>

## Key Findings

### Finding 1: <title>
<details with sources>

| A        | ...  | ...  | ...      |
| B        | ...  | ...  | ...      |

## Recommendations

### Primary Recommendation
<what and why>

### Alternatives
<backup options>

### Avoid
<what not to do and why>

1. [Source 1](url)

```

---

### Step 5: Validation

Before finalizing:
- [ ] Cross-reference multiple sources
- [ ] Check recency (is info current for 2025?)
- [ ] Verify claims with code/docs
- [ ] Note conflicting information
