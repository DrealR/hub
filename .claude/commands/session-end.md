# Session End

End the current session with full summary and handover.

---

## Composable Command

**This command automatically includes:** `handover`

---

## Session Wrap-Up Protocol

### Step 1: Load Current Session

Read from `.claude/.current-session` and load session file.

### Step 2: Capture Final State

```bash
git log --oneline --since="<session start>"
git status
git diff --stat HEAD~<commits>
```

### Step 3: Calculate Metrics

- **Duration:** Start to now
- **Commits:** Count during session
- **Files changed:** List with line counts
- **Goals completed:** Check off completed items

### Step 4: Generate Handover (via handover)

Automatically create handover documentation:
- Current state of work
- What's complete vs in-progress
- Blockers encountered
- Decisions made
- Next steps for continuation

### Step 5: Update Session Document

```markdown
---

## Session Summary

**Ended:** <timestamp>
**Duration:** <X hours Y minutes>

### Metrics
| Metric | Value |
|--------|-------|
| Commits | 5 |
| Files Changed | 12 |
| Lines Added | +234 |
| Lines Removed | -89 |

### Goals
- [x] Goal 1 - Completed
- [ ] Goal 2 - 60% done

### Key Accomplishments
1. Implemented feature X
2. Fixed bug Y
3. Refactored module Z

### Handover Notes
<auto-generated from handover command>

### Next Session Should
1. Complete Goal 2
2. Address PR feedback
3. Write missing tests
```

### Step 6: Clear Session Marker

Remove `.claude/.current-session`.

---

## Linked Commands

This is typically the final command, but you can also use:
- `/project:flow end` - Same result via orchestrator
- `/project:push` - If you haven't pushed yet
