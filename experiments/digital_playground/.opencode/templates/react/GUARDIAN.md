# Guardian Framework Integration

This React project uses Guardian Framework for AI-assisted development.

## Getting Started

1. Run `./opencode-dual-agent.sh` to start the workflow
2. Use Plan agent for component architecture
3. Use Build agent for implementation with TDD
4. Use Guardian agent for code review
5. Use Vision agent for UI/UX feedback

## Best Practices

- Write component tests before implementation
- Use functional components with hooks
- Keep components small and focused
- Document prop types
- Use React Testing Library
- Document anomalies in `.opencode/anomaly-ledger.json`
